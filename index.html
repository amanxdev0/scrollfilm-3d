Reverse-engineered

How this exact page works.

Four tricks. No video files, no frameworks, no build step. Open your devtools and check — the canvas never moves, only the camera inside it does.

01 A fixed canvas, a very tall page

The 3D film is a <canvas> pinned with position: fixed. The page body is ~700 viewport-heights tall, so scrolling gives the film a long timeline to scrub.

#film { position: fixed; inset: 0; z-index: 0; }
#content { position: relative; z-index: 1; }
body { height: 700vh; } /* the timeline */

02 Scroll becomes a playhead

One number drives everything: scroll progress from 0 to 1. Camera paths, colors, fog and object visibility are all pure functions of it.

addEventListener('scroll', () => {
  const max = document.documentElement.scrollHeight - innerHeight;
  target = scrollY / max; // 0 → 1, the playhead
}, { passive: true });

03 Interpolation, not snapping

This is the 20→40 fps trick. Scroll handlers fire irregularly, so the render loop eases the rendered position toward the target every frame, with frame-rate-independent damping. Janky input in, buttery motion out.

function frame() {
  requestAnimationFrame(frame);
  const dt = Math.min(clock.getDelta(), 0.1);
  const k = 1 - Math.exp(-dt * 5.5); // damping
  smooth += (target - smooth) * k;   // interpolate
  render(smooth);                    // draw the film
}

04 Real HTML on top

Chapters are ordinary sections in normal document flow. Each one fades in only while the playhead is inside its range — the film and the words stay in sync because they read the same number.

document.querySelectorAll('.chapter').forEach(el => {
  const a = +el.dataset.from, b = +el.dataset.to;
  el.classList.toggle('is-active', smooth > a && smooth < b);
});

Why it holds up on a normal laptop

  • One scene, zero video. Procedural geometry — no 4K video decode, no giant downloads.
  • Interpolated playhead. Input sampled at ~20 Hz, rendered at display rate. Damping hides the gaps.
  • Adaptive resolution. Pixel ratio steps down if fps drops, and back up when there's headroom.
  • Cheap materials. Additive points and wireframes — no post-processing pipeline, no shadows.
  • Respects reduced motion. With prefers-reduced-motion the film renders one still frame.
